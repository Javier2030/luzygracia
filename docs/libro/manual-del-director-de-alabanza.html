Manual completo del director de alabanza: repertorio, listas, ensayos, sonido, audiciones, filtro teológico de canciones y formación de relevo, con plantillas listas para usar.

La promesa de estas páginas

Vas a salir con el oficio armado: una matriz de repertorio, un método para armar la lista del domingo, un ensayo de noventa minutos que sí rinde, un filtro teológico para las canciones, un proceso de audición, un protocolo de sonido y un plan de doce meses para formar a quien te reemplace.

Para quién es: Directores de alabanza de iglesias pequeñas y medianas, músicos que acaban de recibir el cargo sin manual, pastores que quieren ordenar su ministerio de música y cualquiera que dirija el canto congregacional con más ganas que método.

Lo que te llevas

  • Quince capítulos y cada uno entrega una herramienta: una matriz, un guion, un cronograma o una lista de verificación.
  • Una matriz de repertorio de cuarenta canciones con seis columnas y una regla de rotación que evita el desgaste.
  • La plantilla para armar la lista del domingo, con flujo, tonalidades y transiciones.
  • Un filtro teológico de ocho preguntas para aprobar o descartar cualquier canción.
  • El cronograma minuto a minuto de un ensayo de noventa minutos que rinde.
  • Una lista de doce puntos para la prueba de sonido y el orden correcto de monitores.
  • El formulario de audición y un proceso de incorporación de tres meses para músicos nuevos.
  • Un plan de doce meses para formar al director que te va a reemplazar.
